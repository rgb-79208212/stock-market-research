# A 股市场状态研究｜A-Share Market State Research

一个基于 Python、Streamlit 和金融行情 API 的 A 股市场状态研究原型。项目通过主要指数行情、股票涨跌分布和数据质量检查，帮助用户理解特定数据时点的市场整体表现。

本项目关注的是**市场描述、数据可信度与研究过程的可追溯性**，不提供价格预测、个股推荐或仓位建议。

## 1. 项目目标

- 展示主要 A 股市场指数的价格与涨跌幅。
- 统计上涨、下跌、平盘股票数量及其占比。
- 检查数据完整性、重复记录、缺失值和分页时间戳。
- 区分 API 返回的观测数据、规则性描述与尚无法确认的事项。
- 在数据质量不足时明确提示限制，避免把不完整数据包装成确定结论。

## 2. 主要功能

- **主要指数行情**：获取上证指数、深证成指和沪深 300 的行情快照。
- **市场广度分析**：在满足数据质量要求时，统计上涨、下跌和平盘股票分布。
- **数据质量检查**：检查记录数量、重复代码、缺失涨跌幅和分页时间戳。
- **来源与时间展示**：展示数据来源和 API 返回的时间信息。
- **质量异常提示**：当分页时间戳不一致等问题影响统计可靠性时，提示用户，而不是直接输出未经充分验证的正式结论。

## 5. 本地运行

### 环境要求

建议使用 Python 3.12，并在项目根目录执行以下命令。

创建虚拟环境：

```powershell
py -3.12 -m venv .venv
```

激活虚拟环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

### 配置 API Key

在当前 PowerShell 会话中设置环境变量：

```powershell
$env:HITHINK_FINANCE_API_KEY = Read-Host "请输入 Fuyao API Key"
```

请在提示中输入自己的 API Key，不要将密钥写入源代码、README、测试文件或 Git 仓库。

该命令设置的环境变量只在当前 PowerShell 会话中有效。关闭终端后，通常需要重新设置。

### 启动应用

在项目根目录运行：

```powershell
python -m streamlit run app.py
```

Streamlit 启动后，根据终端显示的本地地址打开应用。

## 6. 数据处理与质量原则

### 市场广度统计口径

对具有有效 `price_change_ratio_pct` 的股票记录进行分类：

- 上涨：涨跌幅大于 0。
- 下跌：涨跌幅小于 0。
- 平盘：涨跌幅等于 0。
- 缺失或无效涨跌幅：不计入有效涨跌分类，并纳入数据质量统计。

涨跌占比以具有有效涨跌幅的记录数为分母，而不是无条件以 API 报告的股票总数为分母。

### 数据质量限制

API 返回的时间戳用于描述数据服务报告的数据时间，不应自动视为交易日确认信息，也不代表所有分页结果来自同一个原子化市场快照。

当前实测中，全市场股票快照共返回 5,578 条记录，其中 5,570 条具有有效涨跌幅、8 条缺失涨跌幅。分页结果存在不同时间戳，因此应用会阻止输出正式的市场广度结论。

这项检查是刻意设置的数据质量保护措施，不应为了展示统计结果而直接取消。

**重要：** 获取到数据不等于获得了当前交易时段的实时行情。非交易日、延迟更新、分页时间差及上游数据状态都可能影响解释。展示结果时应结合实际数据时间判断，不能仅凭 API 请求成功就断言数据代表当前市场。

## 8. 当前限制与后续改进

- 分页时间戳不一致时，当前应用不输出正式的市场广度结论。
- API 时间戳不能单独证明数据对应的交易日，也不能证明不同接口使用相同的市场快照。
- 缺失字段、接口权限、上游服务故障或延迟更新可能影响分析结果。
- 当前规则属于描述性统计，不代表经过验证的预测信号。
- 尚需进一步验证数据跨分页一致性、非交易日处理和异常情况下的用户提示。
- 本仓库是否已部署为公开在线应用，以实际部署状态为准。
