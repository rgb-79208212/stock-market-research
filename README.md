# A 股市场状态研究｜A-Share Market State Research

> **在线体验**：https://stock-market-research-ygbtfnt7pgmndj6e9eoz7k.streamlit.app
>
> **源代码**：https://github.com/rgb-79208212/stock-market-research
>
> **测试说明**：[docs/TESTING.md](docs/TESTING.md)　|　**AI 使用记录**：[docs/AI_USAGE_AND_VALIDATION.md](docs/AI_USAGE_AND_VALIDATION.md)

一个基于 Python、Streamlit 和金融行情 API 的 A 股市场状态研究原型。项目通过主要指数行情、股票涨跌分布、数据质量检查和透明的规则分类，帮助用户理解特定数据时点的市场表现。

本项目关注**市场描述、数据可信度与研究过程的可追溯性**，不提供价格预测、个股推荐、仓位建议或交易信号。


## 1. 目标用户

- **主要用户**：A 股个人研究者、量化研究入门者、金融数据产品评审者。
- **使用场景**：在盘中/盘后快速了解"当前全市场涨跌分布 + 主要指数方向"，
  并确认这份数据**是否足够可信**用于进一步研究。
- **不面向**：需要交易信号的实盘投资者、需要个股推荐的用户。

## 2. 产品设计思路

- **先质量、后结论**：任何市场广度或状态分类都必须先通过数据质量与新鲜度门槛，
  门槛未过时只展示限制说明，不展示"正常"结论。
- **事实 / 归纳 / 不确定三段分离**：结构化报告把"可核查事实"、
  "规则解释"、"尚未验证的假设"分开展示，避免混为一谈。
- **AI 只解释、不判断**：DeepSeek 仅基于已生成的结构化报告做语言解释，
  不重新判断市场状态、不预测涨跌、不给仓位建议。
- **默认极简、诊断可展开**：主视图只展示结论与证据，
  数据质量 / 时间戳 / 接口细节全部收进「数据诊断」Tab，
  避免技术细节干扰阅读。

## 3. 项目目标

- 展示主要 A 股指数的价格与涨跌幅。
- 在数据质量满足要求时，统计上涨、下跌和平盘股票的数量及占比。
- 检查记录完整性、重复代码、缺失值、分页时间戳及行情时效性。
- 区分观测事实、规则性归纳和仍存在的不确定性。
- 当数据质量或适用条件不足时，明确说明限制，不把不完整数据包装成确定结论。
- 为后续历史验证、研究复核和功能扩展保留清晰边界。

## 4. 主要功能

- **主要指数行情**：获取上证指数、深证成指和沪深 300 的行情快照。
- **市场广度分析**：在满足数据质量门槛时，统计上涨、下跌和平盘股票的分布。
- **规则性市场状态分类**：结合市场上涨占比和三个主要指数的方向，生成可解释的描述性分类。
- **数据质量检查**：检查记录数量、重复代码、缺失或无效涨跌幅、分页时间戳等。
- **时效性检查**：检查股票与指数快照的时间信息，并提示缺失、过期或异常时间戳。
- **研究报告**：整理事实、解释、假设、证据质量、适用性、置信度依据和状态重新评估条件。
- **AI 辅助解读**：在研究报告通过质量门槛且配置了所需模型参数时，生成辅助解读。AI 输出不替代数据验证。
- **质量异常提示**：数据不满足关键门槛时，阻止将不可靠数据作为正式市场状态结论。

建议使用 Python 3.12，并在项目根目录执行以下命令。

```powershell

激活虚拟环境：

本地开发使用项目根的 `.env` 文件（已在 `.gitignore` 中排除），格式参照 `.env.example`：

```dotenv

在项目根目录运行：

```powershell

## 8. 数据处理与质量原则

### 市场广度统计口径

对具有有效 `price_change_ratio_pct` 的股票记录进行分类：

- 上涨：涨跌幅大于 0。
- 下跌：涨跌幅小于 0。
- 平盘：涨跌幅等于 0。
- 缺失或无效涨跌幅：不计入有效涨跌分类，并纳入数据质量统计。

涨跌占比以具有有效涨跌幅的记录数为分母，而不是无条件以 API 报告的股票总数为分母。该统计按股票记录数量计算，不是市值加权结果。

### 数据质量与行情时效性

项目会检查关键字段、股票代码、重复记录、分页返回数量、分页时间戳，以及股票与指数快照的时间差等情况。

API 返回的时间戳用于描述数据服务报告的数据时间。它不能单独证明：

- 当前确实处于交易所正式交易时段；
- 日期是交易所认可的交易日；
- 所有分页来自同一个原子化快照；
- 所有股票的最新成交时间相同；
- 股票和指数接口反映完全一致的市场时点。

当分页时间戳不一致、时间戳无效或关键数据质量门槛未通过时，应用应阻止依赖这些数据的正式市场广度或状态结论。

项目当前的交易时段判断不等于完整的官方交易日历验证。法定节假日、临时休市和特殊交易安排仍需可靠日历数据支持。

### 市场状态分类的边界

第一版市场状态分类结合股票上涨占比与三个主要指数的涨跌方向，使用代码中明确设置的规则阈值。阈值属于原型研究规则，**尚未经过正式历史回测验证**。

分类结果用于描述输入数据对应的市场状态，不代表未来方向预测、投资建议或交易信号。状态切换条件是规则重新评估条件，不是买卖触发条件。

### 历史数据验证的边界

仓库包含用于检查历史日线接口和抽样股票数据的诊断脚本。抽样股票历史日线不等于完整的全市场历史快照，因此不能单独证明市场广度阈值有效，也不能据此声称已完成正式的历史回测。

除非另有可复现的历史数据集、明确的样本区间、计算方法和验证结果，否则不应声称市场状态分类已经通过历史验证。
